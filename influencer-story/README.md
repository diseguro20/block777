# Guia para influencer — Blockerino

Vídeo vertical de 21 segundos criado em Remotion para orientar o influencer na gravação dos três Stories da campanha.

## Conteúdo

1. Story 1: apresentar o jogo falando para a câmera.
2. Story 2: gravar a tela jogando.
3. Story 3: adicionar o link e chamar o público.
4. Checklist obrigatório antes da publicação.

## Personalização

Edite `defaultProps` no final de `src/Composition.tsx`:

- `profile`: perfil oficial que o influencer deve marcar.
- `campaignLink`: nome exibido no adesivo de link.

## Comandos

```bash
npm run dev
npx remotion render GuiaInfluencerBlockerino out/guia-influencer-blockerino.mp4
```
